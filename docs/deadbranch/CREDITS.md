# Источники данных / Data sources

В игре используются только данные с открытыми лицензиями и данные автора игры. Материалы, защищённые авторским правом (учебные книги), удалены и не используются.

| Что | Источник | Лицензия / примечание |
|---|---|---|
| Литовские словоформы | Словарь орфографии Hunspell `lt_LT` (© 2000–2020 Albertas Agejevas и участники), через репозиторий [wooorm/dictionaries](https://github.com/wooorm/dictionaries) | BSD (текст лицензии в `tools/src/LICENSE`) |
| Частота слов | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, субтитры OpenSubtitles, 2018) | CC BY-SA 4.0 |
| Английские значения слов, пометки форм (падеж, число, время, лицо), формы глаголов | Английский Викисловарь, выгрузка [kaikki.org](https://kaikki.org/) (Wiktextract) | CC BY-SA 4.0 / GFDL |
| Русские значения литовских слов | Русский Викисловарь, выгрузка [kaikki.org/ruwiktionary](https://kaikki.org/ruwiktionary/) (Wiktextract) | CC BY-SA 4.0 / GFDL |
| Список существительных (751 слово, мн. число, перевод) и база учебного приложения LTLRN (≈ 350 слов и форм) | Автор игры | Принадлежат автору игры |
| Остальные русские переводы | Выполнены ИИ (Claude, Anthropic) и проверены по английским определениям Викисловаря; формы глагола «быть» добавлены вручную | Возможны ошибки; сомнительные переводы не показываются |

Данные, полученные из Викисловаря и FrequencyWords, распространяются на условиях CC BY-SA: при публикации игры нужно сохранить указание источника и ту же лицензию для этих данных.
